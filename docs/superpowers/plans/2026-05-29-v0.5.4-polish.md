**放弃此方案**，改为用一个简单的 CSS 伪元素方案：给 `.code-wrapper` 加一个固定的角标。或者直接跳过。等以后 goldmark 升级支持。

实际上——最简单的方式是在 `splitLineNumbers` 的 `openTag` 解析中同时提取语言信息。由于 goldmark-highlighting 不保留它，我们需要在 markdown 解析阶段就记录。

**最终方案**：在 `collect.go` 中渲染前，用正则提取 fenced code block 的语言名，存入 map，渲染后在 `splitLineNumbers` 中使用。

### Task 4: 暗色模式动态跟随系统

**Files:**
- Modify: `themes/zhenhai/assets/js/main.js:46-51` — 匹配 `auto` 模式时实时响应
- Modify: `themes/zhenhai/layouts/base.html` — 内联脚本同步更新

**问题**：当前 JS 监听 `prefers-color-scheme` 变化，但只在 `localStorage` 为空时响应。当 `colorMode: "auto"` 时，每次都清空 localStorage 才能跟随系统。

**修复**：当用户未手动切换（localStorage 为空即表示 auto 模式）时，跟随系统变化实时切换。

当前代码已正确处理——`matchMedia` listener 中检查 `!localStorage.getItem(STORAGE_KEY)` 才响应。问题是内联脚本设置 localStorage 后，listener 不再工作。修复：在 auto 模式下不设 localStorage。

- [ ] **Step 1: 修改内联脚本**

在 `base.html` 中修改内联脚本，auto 模式不写 localStorage：

```html
<script>
(function(){var m=localStorage.getItem('zhenhai-color-mode');if(!m){m='{{.Config.ThemeConfig.ColorMode}}';if(m==='auto'){m=null;}}if(m==='dark'||(!m&&matchMedia('(prefers-color-scheme:dark)').matches)){document.documentElement.classList.add('dark');}})();
</script>
```

- [ ] **Step 2: 修改 main.js 中的 setTheme**

当 `mode === 'auto'` 时清除 localStorage 让 listener 生效。但当前逻辑是 toggle dark/light。需要改为：toggle 时存入显式值（dark/light），auto 模式下跟随系统。

修改 `setTheme`：

```js
function setTheme(mode) {
  document.body.classList.toggle("dark", mode === "dark");
  if (mode === "auto") {
    localStorage.removeItem(STORAGE_KEY);
  } else {
    localStorage.setItem(STORAGE_KEY, mode);
  }
  document.dispatchEvent(new CustomEvent("zhenhai-theme-change", { detail: { mode: mode } }));
}
```

修改 `toggleTheme`：

```js
function toggleTheme() {
  var next = document.body.classList.contains("dark") ? "light" : "dark";
  setTheme(next);
}
```

修改初始化——当 localStorage 为空时视为 auto，跟随系统：

```js
var stored = localStorage.getItem(STORAGE_KEY);
if (stored) {
  setTheme(stored);
} else {
  setTheme(matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
}
```

```go
type Paginator struct {

    Pages      []*content.Page

    HasNext    bool

    NextPage   int

}
```

在 `newPaginator` 末尾添加 `pageNumbers` 计算：

```go
// Calculate page numbers with ellipsis
var nums []PageNum
for i := 1; i <= totalPages; i++ {
    if i <= 3 || i > totalPages-3 || (i >= page-1 && i <= page+1) {
        nums = append(nums, PageNum{Number: i, IsCurrent: i == page})
    } else if len(nums) > 0 && !nums[len(nums)-1].IsEllipsis {
        nums = append(nums, PageNum{IsEllipsis: true})
    }
}
```

```go
func TestIsHTMLFile(t *testing.T) {
    dir := t.TempDir()
    htmlPath := filepath.Join(dir, "test.html")
    os.WriteFile(htmlPath, []byte("<html>"), 0644)
    txtPath := filepath.Join(dir, "test.txt")
    os.WriteFile(txtPath, []byte("text"), 0644)

    if !isHTMLFile(htmlPath) {
        t.Error("expected html file to be detected")
    }
    if isHTMLFile(txtPath) {
        t.Error("expected txt file to NOT be detected")
    }
    if isHTMLFile(filepath.Join(dir, "nonexistent.html")) {
        t.Error("expected nonexistent file to NOT be detected")
    }

func TestLiveReloadScriptInjection(t *testing.T) {
    dir := t.TempDir()
    htmlPath := filepath.Join(dir, "test.html")
    content := "<!DOCTYPE html><html><head></head><body><p>hello</p></body></html>"
    os.WriteFile(htmlPath, []byte(content), 0644)

    cfg := config.DefaultConfig()
    s := New(cfg, dir)

    w := httptest.NewRecorder()
    r := httptest.NewRequest("GET", "/test.html", nil)
    s.serveHTMLWithLiveReload(w, r, htmlPath)

    body := w.Body.String()
    if !strings.Contains(body, "livereload") {
        t.Error("expected live reload script in output")
    }
    if !strings.Contains(body, "<p>hello</p>") {
        t.Error("expected original content preserved")
    }
    if w.Header().Get("Content-Type") != "text/html; charset=utf-8" {
        t.Error("expected text/html content type")
    }
}

func TestFileServerWithLiveReload(t *testing.T) {
    dir := t.TempDir()
    htmlPath := filepath.Join(dir, "test.html")
    os.WriteFile(htmlPath, []byte("<html><body>hi</body></html>"), 0644)

    cfg := config.DefaultConfig()
    s := New(cfg, dir)
    handler := s.fileServerWithLiveReload(dir)

    // HTML file should get live reload injected
    w := httptest.NewRecorder()
    r := httptest.NewRequest("GET", "/test.html", nil)
    handler.ServeHTTP(w, r)
    if !strings.Contains(w.Body.String(), "livereload") {
        t.Error("HTML response missing live reload script")

    // CSS file should NOT get live reload injected
    cssPath := filepath.Join(dir, "style.css")
    os.WriteFile(cssPath, []byte("body{}"), 0644)
    w2 := httptest.NewRecorder()
    r2 := httptest.NewRequest("GET", "/style.css", nil)
    handler.ServeHTTP(w2, r2)
    if strings.Contains(w2.Body.String(), "livereload") {
        t.Error("CSS response should not have live reload script")
    }
}
```
